投篮进阶 · 收球

把视频里的 pickup 训练拆成六个练习：单手收球、单·双·三运球、短中三分、背后收球和活步收球。选一个，投完点「完成一投」计数；先做对，再加速。

BASE / RIGHT

右手收球

右手运球一次，右手收球，垂直脚步起跳投篮。

  1. 右手低运球一次，球在身体右侧。
  2. 右脚前掌蹬地，右手把球收起来。
  3. 收球后直接垂直起跳，手肘对准篮筐。
  4. 落地保持平衡，再从下一个点开始。

THE METHOD

不是练动作，是练决策

这套训练的目标不是让你多会一招，而是让“看到 → 判断 → 执行”变成不需要思考的事。

01 — RANDOM

随机

没有固定顺序，每个信号独立出现。逼你用阅读代替背诵；一旦开始猜下一个，训练就失效了。

02 — OVERLOAD

过载

加一个球、加一种信号，或者把间隔再砍 0.2 秒。让大脑在轻微过载里工作，再把负荷撤掉。

03 — MEASURE

可测

每组信号数量、动作分布、训练时长都会记录。强度有没有真的上去，数据会告诉你。
